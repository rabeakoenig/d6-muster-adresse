# Gassi-Runden

Eine kleine Seite, auf der Freiwillige des Tierheims Birkenhof (erfundener Fall) ihre Gassi-Runden eintragen.

## Regeln

1. Ein Hund hat höchstens eine Runde je Fenster.
2. Freiwillige machen am Tag höchstens zwei Runden.
3. Die Stufe des Hundes darf die Erfahrung der Freiwilligen nicht übersteigen (Einsteiger führen nur Einsteiger-Hunde aus, Geübte Einsteiger und Geübte, Erfahrene alle).

Pflege: Leitung
